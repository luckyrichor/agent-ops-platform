## 统计方法及比较界限

一致率两两比较使用同一题上正确/错误的双侧精确McNemar（不一致对b/c的p=2×二项分布较小尾，截断1），不一致为0则p=1。ECD与合成分别分析。三版本三对×两来源×全样本/去human两种总体=12个检验，整体Holm校正；同时给原始p、校正p和效应方向，不挑未校正p写显著。

宏F1用20,000次按金标类分层、题目配对自助法，种子20261030（全四类）/20261031（去human）；三版每次共享同一行索引。给单版本百分位95%区间、差值95%区间及跨12个宏F1比较的Bonferroni家族区间（每个约99.5833%）。单版本区间是边际区间，不能仅凭两区间是否重叠推断配对差异。不是原银标抽样层的设计型加权区间。区间条件于本测试集的类别数，不涵盖自然总体类别比例、银标选择偏差、标注者不确定性或新模型请求随机性；这是事后推断，不是预先注册的显著性方案。

去human主口径：移除金标human行后，在查单/退货/clarify三类取固定宏平均；预测为human的行继续算错，不丢失。ECD n=127、合成n=29，因此ECD仅2个human金标不参与主要版本比较。另给“保留全部行但只去掉human宏项”的替代口径，避免两种定义混淆；替代口径仍受human行对其他类FP的影响，不据它作比较结论。类缺失/分母0时F1按原固定宏口径记0，并标明缺类。

**当前没有证据说明混合策略整体优于规则或模型。** ECD各对经Holm校正均未显著，去human三类各差值家族区间均跨0；不能拿human的2条真值支持版本比较。合成全69条中模型/混合相对规则的一致率差异显著（Holm p≈0.000183），必须如实记录；但移除human后对应Holm p≈0.1273，宏F1差值家族区间跨0。这个受生成/筛选偏差影响的局部结果不证明混合整体更好；混合和模型在合成上完全相同。未显著不等于证明相等，区间宽也不是“效果一样”。

## 混合策略定义与逐条分歧

策略按冻结函数选择一条输出：只看当前句的启发式档值为0或1（不是校准概率），阈值0.9；档值<0.9走已保存模型响应，否则走已保存规则响应。规则采用现有业务优先级及承运商咨询边界；模型有最多3段历史，规则/档值只看当前句，这是两者信息范围的差异。

档值顺序：①匹配承运方式选择/更换且不匹配既有履约进度时为1；②否则若含不/别/不要/并/同时/如果/ignore/don't/do not等否定、条件、混合线索则为0；③否则统计人工组（人工/投诉/盗刷/隐私及英文对应词）、物流组（物流/快递/发货/配送及英文对应词）、退货组（退货/退款/换货及英文对应词），恰好命中一组为1，零组或多组为0。先命中的承运边界分支优先于后续线索；这份说明仅解释冻结实现，没有重新执行路由或调整触发条件。

ECD模型/规则53条分歧里，47条走模型，6条走规则。6条规则覆盖里1条纠正模型、4条覆盖原本正确模型而变错、1条两版都错，所以混合比模型净少3条正确。合成29条规则/模型分歧全部走模型，另15条规则分支与模型本来一致，故69条输出完全一致。当前启发式并未识别模型过度触发clarify的风险，矩阵接近模型正是分支选择的结果。
