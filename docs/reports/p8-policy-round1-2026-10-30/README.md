固定种子20261030，未用ECD候选池最多600条，按银标四层各选50；稀有层不足用模型生成口语合成顾客句补齐，source=合成改写。生成只用固定动作定义，不引用ECD。银标与被测模型均为配置的deepseek-flash，不能作为真值；银标只决定抽谁。记录ECD各层N_h/n_h/π/权重；合成生成没有自然总体抽样权重。每银标层50不保证人工最终每类至少30，待人工标注后如实报告覆盖。
